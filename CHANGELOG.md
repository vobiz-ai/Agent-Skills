# Changelog

All notable changes to the Vobiz agent skills plugin.

## 1.2.0 - 2026-10-23

- Seventeen skills: adds `vobiz-reports` (dated Markdown reports from Vobiz
  account data) and `vobiz-campaign-planner` (plan and run an outbound voice
  campaign end to end), and syncs every skill with the Vobiz docs.
- `vobiz-forward-deployed-engineer`: corrects the 140-series calling hours to
  10 AM-8 PM.
- README: updated skill counts and table, full frontmatter guidance, Gemini CLI
  and Cursor install examples, `--all` behaviour, Node.js 22.20 or newer,
  canonical `www.vobiz.ai/docs` links, support and security contacts, and a
  Related section for the Vobiz MCP Server and Vobiz CLI.
- Plugin manifest: adds `privacyPolicyUrl` and removes unreachable `$schema`
  URLs.

## 1.1.0

- Syncs all fifteen skills from the Vobiz docs.
